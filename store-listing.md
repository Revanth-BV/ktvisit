# KTVis.IT — Chrome Web Store Listing

## Product name
KTVis.IT

## Short description
Record browser walkthroughs locally and turn everyday work into reusable knowledge-transfer videos.

## Single purpose
KTVis.IT is a browser-based knowledge-transfer recorder that captures a visual walkthrough of work performed in Chrome and saves the resulting recording locally for future reference.

## Detailed description
KTVis.IT turns a live browser walkthrough into reusable knowledge-transfer material.

Instead of repeating the same KT session for every new joiner, record the process once while you perform it in Chrome. KTVis.IT lets you choose what to capture, control the recording directly from the browser, add chapters at important points, pause and resume when needed, and create a video for later reference.

### Built for practical KT
• Record a browser tab, window, or screen using Chrome's capture permission flow.
• Add chapters while explaining important steps.
• Pause and resume without leaving the workflow.
• Stop the session and create a local video.
• Preview and download the resulting recording.
• Keep recordings on the user's computer — KTVis.IT does not upload recordings to a developer-operated server.
• No audio recording.

### Privacy-first by design
KTVis.IT is designed to operate locally. Recording data and session information are kept in Chrome's local extension storage and the generated video can be downloaded to the user's computer. The extension does not use a developer-operated backend, analytics service, advertising network, or remote code.

### Useful for
• New-joiner onboarding
• Project knowledge transfer
• Application walkthroughs
• Support procedures
• Operational runbooks
• Repeated browser-based processes
